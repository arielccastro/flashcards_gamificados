# 📚 App Concurseiro - Flashcards Gamificados (MVP)

Uma aplicação de flashcards focada em concurseiros, utilizando o algoritmo de Repetição Espaçada (SM-2 adaptado) e elementos de gamificação para manter a consistência nos estudos.

## 🚀 Tecnologias Utilizadas
* **Backend:** Python + FastAPI
* **Banco de Dados:** SQLite (Embutido, sem configuração extra)
* **Frontend:** HTML5, JavaScript Vanilla e TailwindCSS
